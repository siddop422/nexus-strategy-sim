# Sovereign — World Society Simulator (Nexus)

Real-time multiplayer geopolitical, economic, and society simulation.

## Deploy

This repo is set up for Netlify static frontend builds (`vite build` → `dist`).

Full live multiplayer requires the Node/WebSocket server (`server.ts`) on a Node host (Railway, Render, Fly.io). The static frontend supports offline / demo mode without the server.
